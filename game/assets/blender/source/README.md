# Soulstead Blender Source Assets

`realistic_human_bases.blend` contains the extracted realistic male human base
mesh from Blender Studio's Human Base Meshes v1.4.1 bundle.

- Source bundle: Blender Studio Human Base Meshes v1.4.1
- License: CC0
- Used as an anatomical base for Soulstead V20 humanoid production meshes.
- Project-authored clothing, armor, materials, sprite cameras, and export logic
  remain in Soulstead's Blender pipeline.
