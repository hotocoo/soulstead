# Soulstead authored Blender assets

Generated by `tools/blender/advance_soulstead_assets.py` using the base authored builders.

Each asset has an editable `.blend`, Godot-ready `.glb`, and four 1024px transparent sprite views.

Texture catalog: 2048px PNG albedo, packed ORM (AO/roughness/metallic), and tangent-space normal maps under `textures/`. Smooth authored forms receive adaptive applied subdivision: coarse meshes receive two levels, while already-dense primitives receive one to keep Godot-ready GLBs practical.

Character refinement: V12 consolidated Y-up hero meshes for `gravewarden`, `ash_husk`, `cinder_stalker`, `echo`, and `villager`, replacing accumulated exploratory V4-V11 core volumes with clean torso lofts, shared-ring joint-chain limbs, controlled radial density, grounded feet, authored focal details, and regenerated four-view transparent sprites. `cinder_stalker` uses a dedicated X-axis body loft and four articulated legs. Export topology is cleaned for duplicate/degenerate geometry and uses conservative per-mesh density budgets rather than a blanket reduction.

Topology optimization: exported meshes over 1500 vertices receive staged collapse budgets (70% above 1500, 58% above 3000, 48% above 7000), while authored low-density meshes retain their topology. Each mesh stores `topology_vertices`, `topology_polygons`, and `topology_budgeted` audit properties in the editable `.blend` source.

Structural refinement: seventh-pass settlement upgrades add physical gable geometry, recessed door/window framing, exposed rafters, joinery braces, forge/hood/tool-rack details, palisade bracing and caps, memorial plinth/borders, and ledger-board framing while preserving the established asset footprints and filenames.

Weapons: ashblade, reaper_pike, widow_maul, hearth_knife.
Settlement: hearth, memorial, settlement_house, smithy, palisade, ledger_board, pyre_flask.
World: vale_tree, vale_rock. `vale_tree` receives connected tapered root geometry and a shaped root flare; `vale_rock` retains deterministic surface deformation without detached fracture pieces.
Characters/enemies: villager, ash_husk, cinder_stalker, gravewarden, echo.
